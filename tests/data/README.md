# Fixture provenance

`linear.bsp` is Aria-owned synthetic polynomial data, generated by
`tools/datasets/make_synthetic_fixture.py` with SpiceyPy 8.2.0/CSPICE.
It contains analytic Type 2 centre-chain/precedence segments and a Type 3
segment whose stored velocity intentionally differs from position's derivative.
It contains no JPL trajectory data. Its expected values derive from the explicit
polynomials, not from Aria outputs. Apache-2.0 applies to this synthetic fixture.

`reference-de442.json` is generated independently by CSPICE and Skyfield via
`tools/datasets/reference_fixture.py`. It records the actual kernel hash,
versions, epochs, frames and correction settings. Expected outputs are not
computed with Aria's position pipeline.
